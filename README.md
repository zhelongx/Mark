# ZhelongX / Mark

一个可收起、可拖动的屏幕标注工具架。紫色萝卜位于顶端：点击展开/收起，拖动移动整套工具架；按住 Shift 点击最小化到托盘，右键打开托盘/退出菜单。

## 当前 Windows 版功能

- 鼠标左键或数位笔点按工具架上的铅笔、荧光笔，都会进入或恢复实时透明标注层；不会冻结、替换或缩放屏幕内容。工具架在绘制期间始终可见、可操作，绝不避让；萝卜圆形手柄及其安全边界不接收笔迹，工具架空白区可继续绘制。
- 数位笔 `PointerEvent.pressure` 压感：压力同时影响笔触宽度与墨色浓度；鼠标使用稳定的中等压力回退。
- 快捷键不注册为全局快捷键，仅在实际绘制中生效：`Ctrl+Z` 撤销、`Ctrl+Shift+Z` 重做、`Ctrl+E` 清空、`E` 切换橡皮、`[` / `]` 调整笔刷或橡皮大小；`Esc` 或点击萝卜立即退出绘制但保留笔迹。
- 鼠标和数位笔均可操作工具；相机在没有笔迹、暂停或绘制时都可进入矩形截图。松开选区后，真实截取的画面会冻结在米白描边的图框内，并在下方提供“剪切板 / 取消 / 保存”文字按钮；完成后自动回到进入截图前的暂停或绘制状态，保存为 PNG 时再显示 Windows 文件对话框。
- 暗色模式、自动收起延时、工具架位置持久化、系统托盘常驻。

## 运行

双击 [启动 ZhelongX Mark.cmd](./启动%20ZhelongX%20Mark.cmd)，或在安装依赖后执行 `pnpm start`。

首个完整验证目标为 Windows。核心绘制与界面层使用 Electron/Chromium 跨平台 API；macOS 与 Linux 需要分别验证屏幕采集和系统置顶权限。
